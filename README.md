# Home-Automation-UART-based
Bluetooth Home Automation System using Arduino UNO and HC-05 module. Controls 3 loads (Lamp, Motor, LED) via 2N2222 NPN transistor-driven 5V relays. Smartphone sends single-character UART commands at 9600 baud. Supports ON/OFF, toggle, ALL ON/OFF, and status query. Simulated in Proteus 8.
